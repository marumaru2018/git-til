# React でコンポーネントが再実行（再描画）されるタイミング

意図しない再描画が発生するとパフォーマンスが低下する原因になるため state や props を増やしすぎるのは危険です。

- state の状態が変化した場合
  ステートとして定義した値が更新された場合、対象のコンポーネント全体が再描画されます
- コンポーネントに渡された props の値が更新された場合
  コンポーネントの引数である Props が更新された場合も対象コンポーネントは再描画されます
- 親コンポーネントが再描画された場合
  親コンポーネントが再描画されると、そこから呼び出される子コンポーネントも再描画されます

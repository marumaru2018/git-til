# Reactにおける配列操作

配列の不変性
React は State が別のオブジェクト/配列になったかを確認する
→中身ではなく「箱」自体が変わったかどうかを確認。
配列を直接変更すると、参照が同じなので React は変更に気づかない
新しい配列を作成することで、React が変更を検知して再レンダリングする

**元の値を変更するのではなく、新しい値を作成するアプローチで、状態を更新すること**

## 配列操作のパターン

- 配列に追加：

```
setMemos([...memos, newMemo]); // 末尾に追加
setMemos([newMemo, ...memos]); // 先頭に追加
```

- 配列から削除：

```
setMemos(memos.filter((memo) => memo.id !== targetId));
```

- 配列を更新：

```
setMemos(memos.map((memo) =>
memo.id === targetId ? { ...memo, text: newText } : memo
));
```

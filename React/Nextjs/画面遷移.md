# 画面遷移

## ページ間の遷移

- `<Link>`を使用

```
      <Link href="/about">
        Aboutページへ
      </Link>
```

**普通の HTML の`<a>`タグとの違いは、Link コンポーネントを使うことで、ページ遷移時にページの再読み込みが発生しない**

## リンクで画面遷移

Nextjs のリンクを使用

```
import Link from "next/link";
export default function Page1() {
  return (
    <div>
      <Link href="/page2">Page2</Link>
    </div>
  );
}
```

## 遷移先の画面に値を受け渡す

```
import Link from "next/link";

export default function Page1() {
  return (
    <div>
      <Link href={{
        pathname: "/page2",
        query: { id: '99' }
      }}>Page2</Link>
    </div>
  );
}
```

## GET パラメータの取得

```
"use client";
import { useSearchParams } from "next/navigation";
import { useRouter } from "next/navigation";
import { use } from "react";

const Page2 = () => {
  const searchParams = useSearchParams();

  return (
    <div>
      <h1>Page2</h1>
      <p>id:{searchParams.get("id")}</p>
    </div>
  );
};
export default Page2;
```

## イベントを契機にする、もしくは処理完了時に画面を遷移させる

next/navigation を使用
useRouter という hooks をインポートして使用します。
画面遷移は useRouter を呼び出して router.push で遷移先を指定します。

```
"use client";
import { useSearchParams } from "next/navigation";
import { useRouter } from "next/navigation";
import { use } from "react";

const Page2 = () => {
  const searchParams = useSearchParams();
  const router = useRouter();

  const handlerButtonClick = () => {
    router.push("./page1?id=999");
  };
  return (
    <div>
      <h1>Page2</h1>
      <p>id:{searchParams.get("id")}</p>
      <button onClick={handlerButtonClick}>page1へ</button>
    </div>
  );
};
export default Page2;
```

# 動的ルーティング

## パスパラメータの取得

Next.js 13+ (App Router) では params オブジェクトを使う必要があります。

これは Next.js の App Router の仕様で、ダイナミックルートのパラメータは必ず params プロパティを通じて渡されます。

localhost:3000/user/10
上記の URL を開いた際にユーザー ID が 10 のユーザーの情報を表示したいケースを考えます
ユーザー ID は動的に変わるため 10 というフォルダを作る訳にはいきません。
そのような場合は以下のように [] で受け渡す値を指定したフォルダを作成します
以下の例では id という名前にしていますが [user_id] のように任意の名称を指定可能です。

パターン 1: params オブジェクトから直接使用

```
export default function UserPage({ params }: { params: { id: string } }) {
return (

<div>
<h2>User Page for ID: {params.id}</h2>
</div>
);
}
```

パターン 2: 分割代入で取得

```
export default function UserPage({ params }: { params: { id: string } }) {
const { id } = params;
return (

<div>
<h2>User Page for ID: {id}</h2>
</div>
);
}
```

パターン 3: type エイリアスで定義
type UserPageProps = {
params: { id: string }
};

export default function UserPage({ params }: UserPageProps) {
return (

<div>
<h2>User Page for ID: {params.id}</h2>
</div>
);
}

localhost:3000/user/10
上記アドレスから 10 という値を取得する為のコードが右になります。

これまで page.tsx のコードは特に引数などを指定していませんでしたが、URL からパラメータを取得する場合は 引数として params オブジェクトを指定します。

params はフォルダ名 [***] で指定した名称の string 型の値を持つオブジェクトです。

```
type UserPageProps = {
params: {
id: string;
};
}
export default function UserPage(
{params}: UserPageProps
) {
const { id } = params;
return (

<div>
User {id}
</div>
);
}
```

## GET パラメータ取得

localhost:3000/goods?item_id=99
上記アドレスから 99 という商品コードを取得する為のコードが右になります。

useSearchParams という関数をインポートしています。React ではこの use\*\*\*という名前の付いた関数を（hooks と呼ばれる）を多用します。

hooks を使用する際は必ずソースコード上部に
“use client”
の記述が必要になります。

"use client";
import styles from "../page.module.css";
import { useSearchParams } from "next/navigation";

export default function GoodsPage() {
const urlParams = useSearchParams();
const id = urlParams.get("item_id");
return (

<div className={styles.page}>
商品 {id}
</div>
)
}

## URL としては使用したくない場合

app/about フォルダの下にスタイルシートを保存する為の css フォルダを作成します。
しかし app 配下に作成したフォルダは通常、URL として認識されるためこのままでは localhost:3000/app/about/css という URL が有効化されてしまいます。
このようなファイル等を保存するフォルダを app 配下に作成したい（URL としては無効化したい）
という場合はフォルダ名の頭に \_をつけることでルーティングを無効化できます。

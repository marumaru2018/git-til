# コンポーネント

React ではユーザインターフェースを、コンポーネントと呼ばれる部品を使って構築する。

ちなみに、React のコンポーネントは、

index.html→main.jsx→App.jsx

の順番で、読み込まれる

## コンポーネントの定義

- コンポーネントは JavaScript の関数として定義する
  ※関数名の先頭は大文字で作成する
  ※関数名は、パスカル・アッパーキャメルケースで、大文字から始める

- 戻り値が複数行になる場合は、()で囲む

```
return (
  <div>
	Hello
  </div>
);
```

- ()と{}の使い分け
  アロー関数の{}は{}内に実行のコードを記述する
  ()は単になにかをグループ化する際に使用

下記の場合、関数コンポーネントで JSX の戻りが複数行なので
()で囲んでいる

```
const Examle = () => (
  <div>
	Hello
  </div>
);
```

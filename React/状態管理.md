# 状態管理ライブラリ

React ではグローバルな状態管理を行う為の便利なライブラリが存在

状態管理ライブラリを使うことで、あるコンポーネント内で定義した状態を
他のどの画面、どのコンポーネントからも簡単に呼び出すことができます。
つまり、props によるバケツリレーや Cookie や localStorage が不要になるという事です。

状態管理ライブラリを使用すると任意の情報をコンポーネント内ではなく
コンポーネント外のストア（store）という領域で管理する事が可能

store とはステートとそれを操作する関数をセットにしたもの
情報を保持する場所がコンポーネント内ではなくなるため
どの画面・どのコンポーネントからでも値のセット・取得が可能になります。

以前は、Redux が使われていた。今は、Zustand

参考
https://qiita.com/daishi/items/deb20d951f532b86f029
https://b13o.com/books/warikan-calculator/4.create-zustand-store

## Zustand とは

Zustand は、React アプリケーションのための軽量な状態管理ライブラリ

グローバルにアクセス可能なストア（store）で、
状態（state）と、更新用の処理（action）を、まとめて管理します。
フックを呼び出すことで、どのコンポーネントからでも、状態を参照・変更することができる

コンポーネント内で、状態を管理する必要がなくなり、
どこからでもアクセス可能な、ストアで状態を管理することが可能

## Zustand（ストア作成）

### ストアで値を管理

```
import { create } from "zustand";

type UserNameState = {
  userName: string;
  setUserName: (userName: string) => void;
};

export const useUserStore = create<UserNameState>(
  (set) => ({
    userName: "",
    setUserName: (userName) => set(() => ({ userName })),
  })
);
```

### store の情報を更新

```
import { useState } from "react";
import { Stack, TextField, Button } from "@mui/material";
import { useUserStore } from "@/stores/useUserStore";

export const SetStore = () => {
  // ZustandのuseUserStoreからセット用関数setUserNameを取得
  const { setUserName } = useUserStore();
  const [text, setText] = useState<string>('');

  return (
  <Stack spacing={2}>
    <TextField onChange={(e) => setText(e.target.value)} />
    <Button
      variant="contained"
      onClick={() => setUserName(text)}>値を保存</Button>
  </Stack>
  )
}
```

### store から取得した情報を表示

```
import { useUserStore } from "@/stores/useUserStore"

export const GetStore = () => {
  // ZustandのuseUserStoreからuserNameを取得
  const userName = useUserStore((state) => state.userName);
  return (
    <div>{userName}</div>
  )
}
```

3. ストアを作成
4. ストアの中身を実装

5. 型定義ファイルを作成
   プロジェクト内の複数ファイルから参照する型定義ファイルを作成する

```src/types/index.ts
export type Expense = {
  paidBy: string;
  description: string;
  amount: number;

```

2. Zustand をインストール

```
npm install zustand
```

3. ストアを作成
   状態を管理する、ストアを作成する。

まず型を定義する。
状態（state）と、更新用の処理（action）に分けて記述できます：

```src/store/useWarikanStore.ts
// src/store/useWarikanStore.ts

import { create } from "zustand";
import type { Expense } from "../types";

// 状態
type State = {
  inputMember: string;
  inputExpense: Expense;
  members: string[];
  expenses: Expense[];
};

// 更新用の処理
type Action = {
  updateInputMember: (inputMember: string) => void;
  updateInputExpense: (inputExpense: Expense) => void;
  addMember: () => void;
  addExpense: () => void;
  removeExpense: (description: string) => void;
};

const useWarikanStore = create<State & Action>((set) => ({
  // initial state
  // actions
}));

export default useWarikanStore;
```

4. ストアの中身を実装

4.1 状態（state）の初期値を実装

```
	const useWarikanStore = create<State & Action>((set) => ({
  // initial state
  inputMember: "",
  inputExpense: { paidBy: "", description: "", amount: 0 },
  members: [],
  expenses: [],
```

4.2 更新用の処理（action）を実装

Zustand では、set 関数を使用して、値を更新する。

````
  // actions
  updateInputMember: (inputMember: string) =>
    set(() => ({ inputMember: inputMember })),
  updateInputExpense: (inputExpense: Expense) =>
    set(() => ({ inputExpense: inputExpense })),
    ```
````

set 関数は、
useState と同じように、状態をイミュータブルに更新する

更新用処理名: (引数) ⇒ set((prevState) ⇒ ({...prevState, ...updatedValues}))
しかし、これは一般的なパターンなので、set 関数は自動で...prevState の部分をマージします。（なので、省略可）
これにより、ユーザーが入力した、メンバー名や、立て替えの記録を、ストアに保存することができます

以下のコードの解説

```
export const useUserStore = create<UserNameState>((set) => ({
  userName: "不明",
  setUserName: (userName) => set(() => ({ userName })),
}));
```

1. create<UserNameState>

Zustand の create 関数でストアを作成
<UserNameState> で型を指定（TypeScript）

2. (set) => ({ ... })

set は状態を更新するための関数
オブジェクトを返して、ストアの初期状態とメソッドを定義

3. userName: "不明"

状態の初期値
最初は "不明" という文字列

4. setUserName: (userName) => set(() => ({ userName }))

状態を更新するメソッド
userName を受け取り、set 関数で状態を更新
({ userName }) は ({ userName: userName }) の省略形

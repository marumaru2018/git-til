# AWS AI 関連資格ガイド

## AWS AI 関連資格の体系

AWS の AI・機械学習関連の資格は、レベル別に以下のように整理されています。

### 認定資格

#### 🌟 Foundational 認定(基礎レベル)

- **AWS Certified AI Practitioner**
  - AI の基礎知識と AWS の AI サービスの理解を証明

#### 📘 Associate 認定(アソシエイトレベル)

- **AWS Certified Machine Learning Engineer - Associate**
  - 機械学習エンジニアとしての実践的なスキルを証明

#### 🎓 Professional 認定(プロフェッショナルレベル)

- **AWS Certified Generative AI Developer - Professional**
  - 生成 AI アプリケーションの開発における高度な専門知識を証明

#### 🏆 Specialty 認定(専門分野)

- **AWS Certified Machine Learning - Specialty**
  - 機械学習における専門的な知識と実装能力を証明

### マイクロクレデンシャル

特定のスキルセットに焦点を当てた短期集中型の認定です。

- **AWS サーバーレスの実証**
- **AWS エージェンティック AI の実証**

---

## 無料で学べるチャンス

AWS は**2026 年 1 月初頭まで**、以下の資格試験の準備教材と模擬試験へのアクセスを**完全無料**で提供しています。

- 『AWS Certified Cloud Practitioner』
- 『AWS Certified AI Practitioner』

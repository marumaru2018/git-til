# Vercel AI SDK

**Vercel AI SDK** とは、**「Web アプリに AI 機能を簡単に組み込むための開発キット」**

## インストール

```
npm install ai @ai-sdk/openai @ai-sdk/react
```

---

## ポイント

- **対象**: Next.js / React アプリに最適
- **機能**:
  - **テキスト生成**（要約、説明文、翻訳など）
  - **チャット機能**（履歴管理付きの自然な会話 UI）
  - **ストリーミング応答**（回答をリアルタイムに表示）
  - **Function Calling**（AI から外部 API や関数を呼び出せる）
  - **画像生成**（DALL·E などのモデル統合）
- **対応プロバイダー**: OpenAI, Anthropic, Google Gemini など複数の LLM を抽象化して利用可能
- **メリット**: API の違いを吸収しているので、**開発者は UI/UX やサービスロジックに集中できる**

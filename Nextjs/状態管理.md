# 状態管理ライブラリ

React ではグローバルな状態管理を行う為の便利なライブラリが存在

状態管理ライブラリを使うことで、あるコンポーネント内で定義した状態を
他のどの画面、どのコンポーネントからも簡単に呼び出すことができます。
つまり、props によるバケツリレーや Cookie や localStorage が不要になるという事です。

状態管理ライブラリを使用すると任意の情報をコンポーネント内ではなく
コンポーネント外のストア（store）という領域で管理する事が可能

store とはステートとそれを操作する関数をセットにしたもの
情報を保持する場所がコンポーネント内ではなくなるため
どの画面・どのコンポーネントからでも値のセット・取得が可能になります。

以前は、Redux が使われていた。今は、Zustand

```
npm install zustand
```

## Zustand（ストア作成）

### ストアで値を管理

```
import { create } from "zustand";

type UserNameState = {
  userName: string;
  setUserName: (userName: string) => void;
};

export const useUserStore = create<UserNameState>(
  (set) => ({
    userName: "",
    setUserName: (userName) => set(() => ({ userName })),
  })
);
```

### store の情報を更新

```
import { useState } from "react";
import { Stack, TextField, Button } from "@mui/material";
import { useUserStore } from "@/stores/useUserStore";

export const SetStore = () => {
  // ZustandのuseUserStoreからセット用関数setUserNameを取得
  const { setUserName } = useUserStore();
  const [text, setText] = useState<string>('');

  return (
  <Stack spacing={2}>
    <TextField onChange={(e) => setText(e.target.value)} />
    <Button
      variant="contained"
      onClick={() => setUserName(text)}>値を保存</Button>
  </Stack>
  )
}
```

### store から取得した情報を表示

```
import { useUserStore } from "@/stores/useUserStore"

export const GetStore = () => {
  // ZustandのuseUserStoreからuserNameを取得
  const userName = useUserStore((state) => state.userName);
  return (
    <div>{userName}</div>
  )
}
```

# カスタムフックとは

状態（state）や副作用（effect）などを含む一連の処理を一つの関数として
まとめる際などに使用する
カスタムフックを使用する事でコンポーネントからビジネスロジックを分離する
事ができ、コードの可読性が上がるだけでなく、複数の画面で同様の処理が
必要になった際にカスタムフック化しておけば再利用が容易にできる。

例えばユーザ情報を取得する処理をカスタムフック化する

- カスタムフックは必ず use\*\*\* という名称で作成する
- カスタムフックは src/hooks ディレクトリに配置するのが一般的
- フック名を useFetchUserData とした場合、ファイル名も useFetchUserData.ts（または.tsx）のように、フック名と一致させるのが慣例
- 同様の処理を一つの関数にまとめる事ができる

## カスタムフックサンプル

```
import { useState } from "react";

export const useFetchUserData = () => {
  type User = {
    name: string;
    email: string;
    website: string;
  };
  // ユーザー情報の管理
  const [user, setUser] = useState<User | null>(null);
  // ユーザー名一覧の管理
  const [users, setUsers] = useState<string[]>([]);

  const getUserData = (id: number) => {
    const fetchData = async () => {
      const response = await fetch(
        "https://jsonplaceholder.typicode.com/users/" + id
      );
      const data = await response.json();
      setUser(data);
    };
    fetchData();
  };

  const getUserList = () => {
    const fetchData = async () => {
      const response = await fetch(
        "https://jsonplaceholder.typicode.com/users"
      );
      const data = await response.json();
      setUsers(data.map((u: any) => u.name));
    };
    fetchData();
  };
  return { user, users, getUserData, getUserList };
};
```

## カスタムフックを参照する

```
"use client";
import { useFetchUserData } from "@/hooks/useFetchUserData";
import { get } from "http";
import { useEffect } from "react";

const UsersPage = () => {
  const { users, getUserList } = useFetchUserData();

  return (
    <div>
      <h1>Users Page</h1>
      <ul>
        {users.map((name, index) => (
          <li key={index}>{name}</li>
        ))}
      </ul>
      <button onClick={() => getUserList()}>ユーザ一覧</button>
    </div>
  );
};

export default UsersPage;
```

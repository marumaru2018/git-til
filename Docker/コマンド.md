# Docker コマンド

- docker run : コンテナを起動する ( 「Hello World」 や Web サーバーを瞬時に立ち上げる)
- docker ps :起動中のコンテナを確認する
- docker stop :起動中のコンテナを停止する
- docker rm: 停止したコンテナを削除する
- docker images : ローカルのイメージ一覧を確認する
- docker rmi : 不要なイメージを削除する

docker run コマンドはイメージをもとに新しいコンテナを作成し、起動する
イメージは Docker Hub に存在する

イメージを検索する
docker search

# 基本操作

## Git の設定を確認

```
git config --list
```

## Git 最初に

```
git init
git add .
git commit -m "initial commin"
```

## 変更コミット

```
git add .
git commit -m "Google 認証追加"
```

## リモートにプッシュ

- 初回 push（ブランチをリモートに作成）
  git push -u origin auth

- または、すでにリモートブランチが存在する場合
  git push origin auth

## 現在のブランチを確認

```
git branch
```

## ブランチ切替

```
git checkout auth
```

## リモートブランチ一覧を表示

```
git branch -r
```

## リモートとローカルの違いを確認

```
git status
```

# Git コマンド

## リモートブランチの一覧を確認

```
git branch -r
```

## 特定のブランチがリモートに存在するか確認

```
git ls-remote --heads origin 特定のブランチ名
```

## リモートの 特定ブランチをローカルに取得する

```
git fetch origin 特定ブランチ:特定ブランチ
```

または、よりシンプルな方法:

```
git checkout -b 特定ブランチ origin/特定ブランチ
```

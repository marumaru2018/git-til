# 特定のブランチを特定のブランチに反映させる

dev ブランチから e2e-test ブランチに最新のソースを反映する方法

`dev`ブランチの内容を`devForTest`ブランチにマージする手順は以下の通りです:

```bash
# 0. 現在のブランチを確認(任意)
git branch

# 1. 最新の状態を取得(どのブランチでもOK)
git fetch origin

# 2. devForTestブランチに切り替え
git checkout devForTest

# 3. devForTestブランチを最新化(カレント: devForTest)
git pull origin devForTest

# 4. devブランチをマージ(カレント: devForTest)
git merge origin/dev

# 5. コンフリクトがなければプッシュ(カレント: devForTest)
git push origin devForTest
```

**各ステップのカレントブランチ:**

- ステップ 1: 任意のブランチ
- ステップ 2 以降: `devForTest`ブランチ

マージ作業は全て`devForTest`ブランチ上で行います。

**注意点:**

- コンフリクトが発生した場合は、手動で解決してから `git add .` → `git commit` → `git push` を実行してください
- マージ前に現在の作業内容をコミットまたは stash しておくことをお勧めします
- リモートに`devForTest`ブランチが存在しない場合は、最初のプッシュ時に `git push -u origin devForTest` を使用してください

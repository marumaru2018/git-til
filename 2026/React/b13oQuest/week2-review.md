## React 学習 Week2 の振り返り（例）

### やったこと

- React の 7 つの基礎概念を体系的に整理
- Vite + Tailwind CSS を使った React プロジェクトのセットアップ
- 三項演算子（? :）を使った条件付きレンダリングの実装
- map() を使ったリスト表示と key prop の理解
- useState を使った状態管理とタブ切り替え機能
- 論理演算子（&&）を使った条件付きレンダリング
- イベントハンドラー（onClick）の実装
- children props を使ったコンポーネント合成
- GitHub Pages へのデプロイと公開

### 新たに得た学び

- 実際にプロジェクトを作ることで、React の理解が深まった
  - Week1 の理論が、実践でどう活きるかを体感できた
- 条件付きレンダリングの使い分けが理解できた
  - 三項演算子（? :）: 2 つの選択肢から選ぶ
  - 論理演算子（&&）: 条件を満たす時だけ表示
- children props の便利さを実感
  - 再利用可能なレイアウトコンポーネントが簡単に作れる
- リストレンダリングでの key prop の重要性が明確になった
  - React が効率的に再レンダリングするために必須
- デプロイの流れを経験できた
  - 開発から公開までの一連の流れを理解

### 感想や今後の改善点

- まだまだ理解していない部分が多いと感じる
- 単なる写経にならないように先に自分で実装してから正解のコードをみるようにしてみた

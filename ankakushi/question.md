- OP25B (Outbound Port 25 Blocking)

- 電子メールの受信者側のメールサーバでの送信ドメイン認証が失敗したときの処理方針を、送信側のドメイン管理者が指定するための仕組み
  DMARC

- DKIM (DomainKeys Identified Mail)
  DKIM は、送信者がメールに「電子署名」というハンコを押す仕組みです。受信側は、そのドメインの DNS サーバーに公開されている「鍵（公開鍵）」を使って、そのハンコが本物か、途中で改ざんされていないかを確認します。

- SPF によるドメイン認証を実施する場合, SPF の導入時に、電子メール送信元アドレスのドメイン所有者側で行う必要がある設定は
  DNS サーバに SPF レコードを登録する。
  SPF を導入する際、送信側（ドメイン所有者）は、「ウチのドメインからメールを送ることを許可しているサーバーの IP アドレスはこれとこれです」という情報を、自社の DNS サーバに「SPF レコード」として書き込む必要があります。

- 無線 LAN で使用される規格 IEEE 802.1X が規定しているもの
  アクセスポイントが EAP を使用して、クライアントを認証する枠組み
  IEEE 802.1X は、LAN に接続しようとする端末が「本当に接続して良い端末か？」をしっかり確認（認証）するための**仕組み（フレームワーク）**です。その認証のやり取りには EAP というプロトコルが使われます。

- 利用者認証情報を管理するサーバ 1 台と複数のアクセスポイントで構成された無線 LAN 環境を実現したい。PC が無線 LAN 環境に接続するときの利用者認証とアクセス制御に、IEEE 802.1X と RADIUS を利用する場合の標準的な方法

アクセスポイントには IEEE 802.1X のオーセンティケータを実装し、かつ、RADIUS クライアントの機能をもたせる。
IEEE 802.1X 認証では、各役割が決まっています。
PC（利用者）: サプリカント (認証申請者) 、
アクセスポイント: オーセンティケータ (認証の仲介者) 、
認証サーバ: 認証サーバ 。
このとき、アクセスポイント（オーセンティケータ）は、PC からの認証要求を認証サーバへ転送する必要があります。この転送に RADIUS プロトコルを使うため、アクセスポイントは「RADIUS クライアント」として動作します。

- 不特定多数の利用者に無料で開放されている公衆無線 LAN サービスのアクセスポイ ントと端末で利用される仕様として、Wi-Fi Alliance の Enhanced Open によって新規に規定されたものはどれか。
  端末でのパスワードの入力なしに、端末とアクセスポイントとの通信の暗号化が可能となる仕様
  Enhanced Open（WPA3 の一部）の最大の特徴は、パスワードの入力がなくても、利用者ごとに個別の暗号化キーを自動的に生成し、通信を暗号化できる点です。これにより、フリー Wi-Fi の利便性はそのままに、安全性を大幅に向上させました。
  Enhanced Open は、カフェや駅などで使われるパスワード入力が不要な公衆無線 LAN（フリー Wi-Fi）のための規格です。

- 無線 LAN の暗号化通信を実装するための規格
  WPA3-Enterprise は, IEEE 802.1X の規格に沿った利用者認証及び動的に配布される暗号化鍵を用いた暗号化通信を実装するための規格である。
  EAP は、利用者認証を行うための**認証の「枠組み」や「手順」**を定めたプロトコル
  RADIUS は、認証情報を一元管理するための認証サーバのプロトコル
  SSID は、Wi-Fi のアクセスポイントを識別するための名前

- IEEE 802.11a/b/g/n で採用されているアクセス制御方式
  IEEE 802.11（無線 LAN/Wi-Fi）では、電波という共有の通信路で、複数の端末が同時に通信して電波がぶつかる（衝突する）のを**回避する（Avoidance）**ために、CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance) という方式が使われる

- 無線 LAN のアクセスポイントがもつプライバシーセパレータ機能 (アクセスポイントアイソレーション)
  同じアクセスポイントに無線で接続している機器同士の通信を禁止する
  プライバシーセパレータ（AP アイソレーション）は、主に公衆無線 LAN で使われる機能です。
  同じアクセスポイントに接続している他の利用者の PC やスマホへ、直接通信できないように「隔離（Isolate）」します。
  これにより、他の利用者からマルウェアを送り込まれたり、データを盗み見られたりするのを防ぎます。

- RFC 8110 に基づいたものであり、公衆無線 LAN などでパスフレーズなどでの認証なしに、端末とアクセスポイントとの間の無線通信を暗号化するもの
  Enhanced Open
  RFC 8110 は「Opportunistic Wireless Encryption (OWE)」という技術を定義しており、Wi-Fi Alliance はこれを「Enhanced Open」というブランド名で規格化しました。
  WPA3 は Wi-Fi のセキュリティ規格の総称

- DNS に対するカミンスキー攻撃への対策は。
  問合せ時の送信元ポート番号をランダム化することによって、DNS キャッシュサーバに偽の情報がキャッシュされる確率を大幅に低減させる。
  カミンスキー攻撃は、DNS サーバからの「本物の応答」が返ってくるより先に、攻撃者が「偽の応答」を送りつける攻撃です。このとき、攻撃者は応答先のポート番号を推測する必要があります。このポート番号をランダムにすることで、推測を非常に困難にし、攻撃を防ぎます。

DNSSEC
「リゾルバ」（キャッシュ DNS サーバとも呼ばれ、8.8.8.8 やプロバイダのサーバが該当）は、権威サーバから受け取った応答（リソースレコード）に付いているデジタル署名を検証します。これにより、その応答が「本物のサーバから来たもの」であり、「途中で改ざんされていない」ことを確認できます。
DNS キャッシュサーバ（リゾルバ）は、デジタル署名を検証することで、受け取った DNS 応答が**正当な管理者（権威 DNS サーバ）**から発行され、改ざんされていないことを保証できます。
DNSSEC の目的は、デジタル署名という技術を使って、DNS の応答が「本物（正当）」であることを確認できるようにすることです。

DNS キャッシュポイズニング攻撃に対して有効な対策
DNS キャッシュポイズニング攻撃は、DNS サーバが問合せた際の「ID（トランザクション ID）」と「ポート番号」を攻撃者が推測し、本物の応答より先に偽の応答を送りつける攻撃です。この ID を毎回ランダム（予測困難）にすることで、攻撃者が推測するのを非常に難しくし、攻撃を防ぎます。（ポート番号をランダム化するのも有効な対策です）

SAML 認証の特徴
IdP (Identity Provider) が利用者認証を行い、認証成功後に発行されるアサーションを SP (Service Provider) が検証し、問題がなければクライアントは SP にアクセスできるようになる。

SAML

標準化団体 OASIS が、 Web サイトなどを運営するオンラインビジネスパートナー間で認証、属性及び認可の情報を安全に交換するために策定したものはどれか。
SAML は、異なるドメイン（例: google.com と slack.com）の間で、「この人は本人確認済みです」というセキュリティ情報（アサーション）を XML 形式でやり取りし、シングルサインオンを実現するための標準規格です 。
認証情報に加え、属性情報と認可情報を異なるドメインに伝達するための Web サービスの仕様
「この人は本人確認 OK です（認証）」「この人は営業部の所属です（属性）」「この人はこのデータを見て OK です（認可）」といった情報を、異なるドメイン（会社やサービス）間で安全に伝えるための仕様です 。

OAuth（オーオース）
Web サーバにある利用者のリソースに、Web サーバに限らない他のサーバが利用者に代わってアクセスすることを許可するための認証プロトコル
「あなたの Twitter アカウントでツイートすることを許可しますか？」といった権限の許可に使われます。

OpenID
利用者 ID として URL 又は XRI (Extensible Resource Identifier) だけを使用することができ、一つの利用者 ID で様々な Web サイトにログインできる仕組み

サイドチャネル攻撃の手法であるタイミング攻撃の対策
演算アルゴリズムに処理を追加して、秘密情報の違いによって演算の処理時間に差異が出ないようにする。
タイミング攻撃は、処理にかかる「時間」のわずかな違いを測定して秘密情報を推測する攻撃です。そのため、どんなデータがきても処理時間が一定になるように、わざとダミーの処理を加えたりして時間を均一化することが対策になります。

サイドチャネル攻撃
暗号処理そのものを解読するのではなく、処理中にかかる消費電力や時間、漏れ出る電磁波といった「脇（サイド）から漏れる情報」をヒントにして秘密情報を盗み出す攻撃

スミッシング
SMS（ショートメッセージ）を使って偽サイトに誘導し、情報を盗むフィッシング詐欺の一種です。

中間者攻擊
中間者攻撃は、通信している二人の間に割り込んで、両方の通信を盗聴したり改ざんしたりする攻撃です。
